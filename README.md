# AI Object Detector

A Python-based real-time object detection project using YOLO and OpenCV.

## Features

* Real-time object detection
* Detects multiple objects
* YOLO-based computer vision
* Python implementation

## Technologies Used

* Python
* YOLO
* OpenCV

## How to Run

Install the required packages and run:

```bash
python main.py
```

## Project Structure

```text
AI-Object-Detector/
├── main.py

```

## Goal

This project demonstrates real-time object detection using a YOLO model.
